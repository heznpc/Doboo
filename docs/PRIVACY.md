# Doboo 개인정보 안내

작성: Heznpc · 2026-10-13 · 현재 구현 기준

Doboo는 iPhone과 Apple Watch에서 캐릭터를 보관하고 사용합니다.
로그인, 광고, 분석 SDK, 추적, 건강 데이터 접근, ChatGPT 계정 연결은 없습니다.
Doboo가 운영하는 서버로 캐릭터나 터치 데이터를 전송하지 않습니다.

캐릭터 파일에는 이름, 제작자 표기, 설정, 말투, 성격과 선택적인 Pets 이미지가 들어갑니다.
사용자가 만들거나 가져온 파일은 앱의 Application Support에 저장됩니다.
갤러리에서 공유하면 **이 필드 전체**가 OS 공유 시트에서 사용자가 선택한 대상에게 전달됩니다.
Dots 지침과 서브에이전트 설정을 내보내도 캐릭터의 설정·말투·성격이 포함됩니다.
사용자가 복사를 누르면 Dots 지침이 시스템 클립보드에 복사됩니다.

Watch로 보내기를 누르면 WatchConnectivity가 캐릭터 파일을 페어링된 Watch 앱으로 전달합니다.
Watch는 파일을 검증하고 저장한 뒤 수신 확인을 반환합니다.
전송 중에는 앱 내부에 임시 파일이 저장되며 전송 callback에서 정리합니다.
공유용 파일 역시 앱의 임시 디렉터리에 생성됩니다.

햅틱·모션·첫 안내와 전송 확인 상태는 UserDefaults에 저장됩니다.
터치 좌표와 눌림 상태는 메모리에서 반응을 계산하는 데 쓰며 기록하지 않습니다.
캐릭터는 앱을 삭제하면 해당 기기의 앱 데이터와 함께 제거됩니다.
기기 백업과 OS 공유 기능은 사용자가 선택한 시스템 설정과 공유 대상의 정책을 따릅니다.

`Resources/PrivacyInfo.xcprivacy`에는 추적 없음, 수집 데이터 없음,
앱 자체 설정 저장을 위한 UserDefaults 접근 사유 `CA92.1`을 선언합니다.
이 선언은 앱에 포함한 기능과 SDK 변경 때 함께 검토해야 합니다.
이 문서는 스토어에 게시된 개인정보 처리방침 URL을 대신하지 않습니다.
